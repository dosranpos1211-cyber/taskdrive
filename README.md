# タスクドライブ スマホ用ランチャー

スマホのホーム画面に「タスクドライブ」のアイコンを置き、タップするとアプリのように全画面で開けるようにするための小さなホームページです。
中身はツール（Google Apps Script のウェブアプリ）を全画面で表示しているだけです。タスクのデータやパスワードは持っていません。
ただし v3.8.1 から、**ログイン状態（30 日有効の合い言葉＝トークン）を、このページを開いたスマホの中に預かります**。スマホでは埋め込んだツールの画面の保存が開くたびに消えるため、このページが代わりに覚えておき、ツールに渡します（下の (f)）。

無料の GitHub Pages に置いて使います。作業は最初の 1 回だけ（10 分ほど）です。

## このフォルダの中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | ランチャー本体（ツールを全画面で表示し、ログイン状態を預かる） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・全画面表示の設定 |
| `sw.js` | Android で「アプリをインストール」を出すための最小の仕組み（ランチャー本体だけを保存） |
| `icons/` | ホーム画面・タブのアイコン |

## (a) GitHub にファイルを置く

1. GitHub のアカウントがなければ作ります（https://github.com/ → 「Sign up」。無料です）。
2. 右上の「＋」→「New repository」を押します。
3. 「Repository name」に `taskdrive` と入れ、**Public**（公開）を選んで「Create repository」を押します。
   - 無料プランで GitHub Pages を使うには Public にする必要があります（下の (d) を参照）。
4. できたページの「uploading an existing file」（または「Add file → Upload files」）を押します。
5. パソコンでこの `launcher` フォルダを開き、**中身すべて**（`index.html`、`manifest.webmanifest`、`sw.js`、`README.md`、`icons` フォルダ）をまとめてブラウザの画面へドラッグ＆ドロップします。
   - `launcher` フォルダそのものではなく、**中身**を入れてください（`index.html` がいちばん上の階層に来るように）。
   - `icons` フォルダはフォルダごとドラッグすれば中の画像も入ります。
6. 下の「Commit changes」を押します。

## (b) GitHub Pages を有効にする

1. リポジトリの「Settings」→ 左の「Pages」を開きます。
2. 「Build and deployment」の「Branch」で `main`、フォルダは `/ (root)` を選び、「Save」を押します。
3. 1〜2 分待ってページを再読み込みすると、上に URL が出ます。
   例：`https://<あなたのユーザー名>.github.io/taskdrive/`
4. その URL をスマホで開き、タスクドライブのログイン画面が出れば準備完了です。

この URL を従業員に伝えてください（チャットワークなどで送ると、スマホでそのまま開けます）。

## (c) スマホのホーム画面に追加する

### iPhone（Safari）

1. 上の URL を **Safari** で開きます（Chrome などでは追加できない場合があります）。
2. 画面下の共有ボタン（四角から上向きの矢印）を押します。
3. 「ホーム画面に追加」を選び、名前が「タスクドライブ」になっていることを確かめて「追加」を押します。
4. ホーム画面の金色のアイコンから開くと、アドレスバーのない全画面で表示されます。

### Android（Chrome）

1. 上の URL を **Chrome** で開きます。
2. 右上の「︙」（メニュー）を押し、「アプリをインストール」または「ホーム画面に追加」を選びます。
3. 「インストール」（または「追加」）を押します。
4. ホーム画面（またはアプリ一覧）の金色のアイコンから開くと、全画面で表示されます。

### うまく表示されないとき

- 15 秒たっても表示されないときは「ブラウザで開く」ボタンが出ます。押すとツールを普通のブラウザで開けます。
- 一度ログインすれば、ホーム画面のアイコンから開いても 30 日間はログインしたままです（v3.8.1）。それでも毎回ログイン画面になる場合は、`index.html`・`sw.js` が新しいものに置き換わっているか（(f)）、ツールが v3.8.1 以降に更新されているかを確かめてください。新しいランチャーに入れ替わるまで、アイコンから 1〜2 回開き直しが必要なことがあります。

## (d) 公開について（安全面）

- リポジトリは Public（誰でも見られる状態）になりますが、入っているのは**このランチャーとツールの URL だけ**です。タスクの内容・パスワード・トークンなどは一切入っていません（トークンは各自のスマホの中にだけ保存されます）。
- ツールの URL はもともと従業員に配っているものと同じです。URL を知っていても、**ログイン ID とパスワードがなければ何も見られません**。
- 同じ GitHub アカウントの GitHub Pages（`https://<ユーザー名>.github.io/` の下）は、すべて同じ「サイト」として扱われ、預かったトークンを読めます。**このアカウントでは、信用できないページ・他人が書いたページを GitHub Pages に公開しないでください。**

## (f) ログイン状態の預かり（v3.8.1）

- ツールは、ログインしたとき・ログアウトしたとき・有効期限が切れたときに、このページへ合い言葉（トークン）を知らせます。このページはそれをスマホの中（このページ専用の保存領域）に覚えます。
- 次にアイコンから開いたとき、ツールが「預けた合い言葉をください」と頼み、このページが返します。返事が 1.5 秒以内に来なければ、ツールはログイン画面を出します。
- このページが答えるのは、**自分の中に埋め込んだ Google のツール画面（`*-script.googleusercontent.com`）だけ**です。ほかのサイトに埋め込まれたとき・ほかの窓からの問い合わせには答えません。
- ツールの側も、合い言葉を **`https://dosranpos1211-cyber.github.io` 以外には送りません**。GitHub のユーザー名を変えた・別のアカウントに置き直した場合は、ツールの `src/ClientJs.html` の `LAUNCHER_ORIGIN` も書き換えて反映する必要があります（書き換えないと、毎回ログインに戻るだけで、壊れはしません）。
- 更新したら、`index.html`・`sw.js`・`README.md` を (a) と同じ手順でアップロードして上書きします。

## (e) ツールの URL が変わったとき

ウェブアプリを「新しいデプロイ」で作り直したなどで URL が変わった場合は、`index.html` の次の 1 行を新しい URL に書き換えます。

```js
var APP_URL = 'https://script.google.com/macros/s/……/exec';
```

GitHub のリポジトリで `index.html` を開き、右上の鉛筆マーク（Edit）で書き換えて「Commit changes」を押せば、数分で反映されます。
（「デプロイを管理」で既存のデプロイを更新した場合は URL は変わらないので、書き換えは不要です。）
